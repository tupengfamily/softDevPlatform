**关键发现（全部免 OCR）**：
- **`JPG 同名 .xls` 规律**：多个省级年鉴网页版只挂 `.jpg`，但**同目录存在同名 `.xls`（BIFF 格式）机读版本**。已在 **四川 / 河南 / 山西 / 辽宁 / 广西 / 福建 / 陕西 / 内蒙古 / 湖南** 9 省验证成立 → 显著扩大免费机读覆盖
- **内蒙古自建 easyquery 平台**：`https://tj.nmg.gov.cn/datashow/easyquery/easyquery.htm?cn=A0103`，接口与 NBS 同构但**未被 WAF 拦截**，可取 2018–2024 省级面积/产量/单产年序（**关键参数位置见 §19**）
- **陕西命名变体**：JPG 名**无横线**（`1208.jpg` / `1208.xls`），与其它省的 `12-08.jpg` 风格不同
- `广东农村统计年鉴2025` 官方整本 ZIP（117 MB / 417 个 Excel），含**县(市、区)级**播种面积+亩产+总产量
- `云南统计年鉴2025` 官方整本 ZIP（10.7 MB / 51 文件），含**县(市)级主要农作物产量**（18-14 四张续表）
- `浙江统计年鉴2025` 在线 HTML 表，数据以 JSON 内嵌，含**市、县级**表
- `江苏 / 安徽 / 吉林` 统计年鉴 2025：Excel 导出的 HTML `<table>`（安徽需 Referer，吉林部分需重试）
- **省级统计公报/解读 2025**：全国 + 12 省 + 2 市，**面积/产量/单产三列齐全**，已结构化为 `省级公报_2025_作物面积产量.csv`（364 行）

> **提取器关键经验（数值准确性的核心）**：
> 1. **子句级归属**：先按「；，、」切子句，数值只归属同子句内最近的作物关键词；跨子句回溯仅在「中间含产量/面积/单产标签且中间无其它作物关键词」时启用（解决「粮食播种面积X；总产量Y」）。
> 2. **增量 vs 水平值**：`增加/减少/比上年` 紧邻的数值是增量，必须排除；但「连续6年增长；总产量3815.3万吨」中的 3815.3 是水平值。
> 3. **单位交替顺序**：`公斤/公顷` 必须排在 `公斤` 之前，否则「192.3公斤/亩」会被截成「192.3公斤」。
> 4. **括号限定语**：「粮食产量（含薯类）2432.3万吨」中的「薯类」在括号内，不得被归属。
> 5. **数字被空格拆分**：PDF/HTML 排版常出现「3 9 3.9」「1 0 1 2 . 4」，需预处理还原。
